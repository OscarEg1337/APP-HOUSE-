# Casa Oscar — App

App Flutter (Android / iOS / Web). Ver el [README principal](../README.md) del repositorio para instrucciones de arranque completas (backend + app).

## Arranque rápido

```bash
flutter pub get
flutter run
```

Antes de correr en un dispositivo real, actualiza `Api.baseUrl` en `lib/main.dart` con la IP LAN del backend.
